This is a single-page audit plus every site-wide signal file. It is not a full-site crawl. If you need every page of a large site evaluated, that is an enterprise arrangement — see section 3.

Depth

The catalogue holds 167 signals across six dimensions: AI Signals, AEO, GEO, AIO, SEO and A2A. Not every signal can be tested on every domain. Signals that cannot be verified from public sources are returned as not applicable, never as failures, and each report states how many were actually tested. A report that says 129 tested means 129, not 167.

Every score is produced by fixed rules applied to evidence the engine actually fetched. No score is generated by a language model. The same domain in the same state returns the same score.

Deliverables

  • Global score plus a score per dimension.
  • A verdict for every signal, with the evidence that produced it — what was fetched, what was found in it, which rule fired.
  • A prioritised action plan, ordered by signal weight, so the first fix is the one that moves the score most.
  • The same report as machine-readable JSON.
  • An observation ID, which is what lets you run a before-and-after comparison later.

Delivery time

Synchronous. The report is returned in the same request, typically in under a minute. There is no queue, no email, no waiting for a human to write it.

What tracking gives you

  • Score history — every observation is stored, so you can see the line rather than a single number.
  • Regression alerts — notification when the score drops, or when a signal that used to pass starts failing. A regression is a fact about a specific signal, not a vague warning.
  • Signal-level diff — which signals changed, in which direction, and the evidence for each change. This is what proves a fix worked.
  • Comparison over time — any two observations of the same domain can be compared, not just consecutive ones.

Alerts are delivered to a callback URL you provide. Email delivery is not wired to a provider yet.

Why you would use it

Sites regress silently. A theme update drops the JSON-LD block, a CDN rule strips a header, someone removes llms.txt during a cleanup. None of these produce a visible error on the page. The monitoring plan exists because the failure mode of AI visibility is silence, not an error message.

4. What is not included

Stated plainly, because the gap between what a tool measures and what a buyer assumes it measures is where disappointment lives.

  • No guarantee of citation or ranking. Third-party AI systems change behaviour without notice and no provider guarantees inclusion. The audit measures observable technical signals within your control. It does not promise a commercial outcome.
  • No legal certification. The report is a technical observation, not a certification and not a legal opinion. For a formal classification under Regulation (EU) 2024/1689, obtain independent legal analysis.
  • No implementation. The action plan tells you what to fix. Fixing it is your work, or a separate engagement.
  • No access to private areas. Only publicly served resources are read. Nothing is installed, no authentication is attempted.
